Rikiki is an HTML presentation toolkit. Give a coding agent a brief and the installed authoring skills, or write the HTML yourself. Components handle slide layouts. The check command inspects the rendered deck and returns diagnostics, including machine-readable JSON, for revision. Rendering produces screenshots for a separate visual review. Automated checks do not judge the argument or validate its evidence: that remains the author's job. Present the result in the browser, bundle standalone HTML or export a PDF. The commands shown are an authoring workflow, not an executed check result. Playwright and the bundler are optional dependencies documented in the setup guide.

Read the evidence. Judge the hierarchy, pacing and visual composition.

Zero reported errors does not certify a persuasive or beautiful presentation.

Mechanical diagnostics and visual editorial review answer different questions. Rikiki's check is useful feedback, but it does not validate facts or guarantee design quality. An author or reviewer needs to inspect the result. This distinction is why the workflow includes screenshots.
